==================================================
1. PRODUCT CONTEXT
==================================================

This product is the future foundation of a modular platform for construction companies.

In the future, separate modules will be added:
- construction management
- cost management
- procurement
- wholesale materials marketplace
- client communications
- rental management
- analytics
- other integrations

But right now, only these parts must be built:

A. Foundation Core
B. Excel Import Center
C. Rental Management

Current data entry mode:
- counterparties are uploaded manually by Excel
- properties are uploaded manually by Excel
- contracts are uploaded manually by Excel

In the future, Excel import may be replaced or supplemented by API integrations.
So the architecture must be import-first, API-ready.

==================================================
2. CORE ARCHITECTURAL PRINCIPLE
==================================================

All business logic must be built around a stable internal domain model.

Current input pipeline:
Excel -> Import Layer -> Core Domain -> Module Logic -> REST API -> UI

Future input pipeline:
External API -> Integration Layer -> Core Domain -> Module Logic -> REST API -> UI

Do NOT build the system in a way that is tightly coupled to Excel.
Excel is only the first input channel.

Every major domain entity should support future sync metadata:
- source_type
- external_id
- sync_status
- last_synced_at

==================================================
7. REQUIRED BUSINESS RULES
==================================================

1. Sales/ownership data and rental data must not be mixed into one flat table.
2. BaseContract and LeaseContract are related concepts but different operational layers.
3. A property can exist without rental mode.
4. Rental mode can be activated only when owner exists.
5. Lease contract can be active only for a property in rental mode.
6. Rental accruals should be generated monthly.
7. Payments can be partial.
8. Deposit handling must support hold/return/withhold.
9. Expenses reduce owner result.
10. Owner statement is calculated, not manually edited.
