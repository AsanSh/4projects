Role: Senior Fullstack Developer (Next.js, Tailwind, Framer Motion) & Database Architect
Objective
Build "BuildFlow OS", a high-end ERP for Construction, Rental, PropTech, and Procurement. Use a unified database core to ensure the "Сводное" (Master Dashboard) consolidates data from all modules in real-time.

1. PREMISES: UI/UX & ANIMATION (The "Premium" Layer)
Design Philosophy: Avoid standard flat sidebars. Use a "Spatial UI" approach.

Sidebar Design: Create a floating, neumorphic stack of tiles for the navigation.

Hover Effects: Use Framer Motion for a "pressed" effect (changing outer shadows to inner shadows) when hovering over menu items.

Action Hub: The "Быстрое создание" section must be a Floating Action Button (FAB) that "blooms" out sub-buttons (New Payment, New Contract) using a circular reveal animation.

Identity Card: The admin profile at the bottom should use a 3D-flip animation on click to reveal settings.

Micro-interactions: Use layoutId from Framer Motion for smooth "liquid" transitions between module tabs.

2. DATABASE ARCHITECTURE (The Core)
Core_Projects: Central registry for all buildings/complexes.

Core_Counterparties: Unified table for Tenants, Buyers, Suppliers, and Contractors.

Core_Transactions: General Ledger storing all financial moves with module_tag.

Currency: Integrate NBKR.kg API for real-time KGS/USD/RUB conversions in the "Операции" tab.

3. MODULE SPECIFICATIONS (As per Screenshots)
A. Construction (Стройка)
Management: Dashboard (ROI, Cost 1m2), Operations (NBKR integration), Project Cards, 10-stage Work Tree.

Resources: Brigade (TG-bot check-ins), Subcontractors (Acts of Work), Materials.

Finance: Interactive Chessboard (Шахматка), Sales Workflow (Seller -> Lawyer), Auto-installments (Начисление).

Planning: Budget (SME upload), Overdue Tracking (Red/Green logic), Multi-level Approval Routes.

B. Rental (Аренда)
Management: Occupancy Dashboard, Unit Registry, Tenant CRM, Contracts (Indexation %).

Finance: Auto Rent-Roll (Monthly billing), Security Deposits, OPEX tracking.

Investors: Equity mapping and automated Dividend Distribution (Profit minus Mgmt Fee).

C. PropTech (Client Portal)
Client View: Investment Dashboard, My Units (with RTSP Live Stream from construction), Document Vault.

Planning: Personal installment calendar and messaging system.

D. Procurement (Закуп)
Workflow: Supplier Rating, Global Goods Catalog, Purchase Orders.

Operations: "Заявки прорабов" – Field requests from construction sites that trigger the procurement cycle.

4. MASTER DASHBOARD (Сводное)
Create a top-level view that aggregates:

Total CashFlow across all modules.

Consolidated P&L.

Cross-module risk alerts (e.g., procurement delays affecting construction deadlines).
